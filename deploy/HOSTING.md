# Где разместить проект на 10 дней без карты

Проверено по официальным страницам 15.11.2026. Аккаунты и серверы не создавались, сайт не публиковался.

В предоставленном PDF (стр. 13–14) наш вариант — **C: веб-страница с backend API**. Хостинг — дополнительная функция. Разрешён любой хостинг, Timeweb только рекомендован. Для сдачи нужны код ZIP/открытый репозиторий и либо живая ссылка, либо подробное видео локальной работы; при видео балл за хостинг не засчитывается. Имена сдаваемых файлов должны содержать ФИО. Нужны также общее видео до трёх минут и ссылка на папку с доступом для жюри.

## Timeweb: обещание верно, но тариф не подходит нашему стеку без переделки

- [Официальный сайт](https://timeweb.com/) заявляет **10 дней без оплаты и привязки карты**.
- [Условия теста](https://timeweb.com/ru/docs/virtualnyj-hosting/tarifnye-plany-hostinga/besplatniy-testoviy-period/): период начинается при создании аккаунта, один раз на аккаунт; исходящие подключения только на порты **80 и 443**; после 10 дней без оплаты аккаунт блокируется.
- [Python-хостинг](https://timeweb.com/ru/services/hosting/python/): перечислены Python 2.7/3.6/**3.10**, Apache mod_wsgi; встроенные БД — MySQL. Для PostgreSQL предлагается отдельный сервер. Обычный внешний PostgreSQL на 5432 во время теста не решает проблему из-за ограничения исходящих портов.

Наш проект использует **Python 3.12 + PostgreSQL + Docker Compose + Gunicorn + Caddy**. Поэтому не стоит оформлять этот shared-hosting в расчёте просто загрузить наш ZIP. До заказа нужно отдельное подтверждение поддержки именно этих компонентов или согласие на смену архитектуры. Переходить на MySQL/SQLite и Python 3.10 скрыто не будем.

## Кандидат для нашего стека: 1Gb.ru Linux KVM

[Официальная страница Linux KVM VDS](https://www.1gb.ru/l_vds5.php) указывает бесплатный тест до 10 дней. В FAQ уточнено: сервер можно создать без оплаты, тест — 10 дней однократно, без привязки карты. В форме отдельно предусмотрена регистрация физического лица.

Полноценный Linux KVM соответствует размещению текущего Docker Compose с Python 3.12, PostgreSQL, Gunicorn и Caddy. Это вывод о совместимости стека; сам сервер мы ещё не получали. До регистрации нужно проверить доступность нужного тарифа и ресурсов именно на тесте. Условия провайдера предупреждают о прекращении теста при нарушениях; гарантировать активацию любого аккаунта или непрерывную работу мы не можем.

## SmartApe: есть существенная оговорка

[Официальная страница NVMe VPS](https://www.smartape.ru/ssd-vps) прямо заявляет **10 дней теста без оплаты и ввода карты**, Linux root/SSH и внешний IP. Это соответствует развёртыванию нашего Docker Compose на собственном Linux-сервере. Поддержка нашего полного стека — технический вывод из наличия полноценного VPS, а не проверенное развёртывание в аккаунте.

[Условия](https://www.smartape.ru/offer): тест одноразовый для услуги; надо выбирать тариф с отметкой «Тест». При проверке актуальной страницы рядом с кнопкой «Попробовать» показано **«Только для юр. лиц»**. Поэтому обычному участнику нельзя обещать бесплатный VPS здесь: сначала необходимо отдельное подтверждение провайдера. Бесплатный период не означает отсутствие регистрации или верификации.

## План после подтверждения выбранного Linux VPS

1. Linux VPS с бесплатным тестом для физлица; ориентир для запаса — 2 ГБ RAM и 20 ГБ диска, если такой тест доступен.
2. Установить Docker/Compose и загрузить проект без локального `.env`.
3. Создать новые серверные секреты; открыть только HTTP/HTTPS, не PostgreSQL.
4. Использовать собственный/бесплатный технический домен, направленный на IP, и конфигурацию Caddy из README. Покупка домена не является обязательным требованием кейса; доступность бесплатного имени/сертификата проверяется отдельно.
5. Миграции → импорт CSV → collectstatic → запуск → проверка регистрации, расчёта и мобильного экрана по публичной ссылке.
6. Планировать срок так, чтобы ссылка оставалась доступна на момент проверки жюри. Экспортировать БД и сохранить ZIP до окончания теста.

Оплата/покупка услуг не нужны для исследования. Саму публикацию выполняем отдельным согласованным шагом после получения доступа к выбранному серверу; пароль/SSH-ключ не публикуются в коде.

## Запасной вариант: Render Free

[Официальные ограничения](https://render.com/docs/free): бесплатные web service и PostgreSQL, БД на 30 дней, сервер засыпает после 15 минут без запросов и просыпается примерно минуту. [FAQ](https://render.com/docs/faq) описывает работу без добавленного платёжного метода: при превышении бесплатных лимитов сервис приостанавливается.

Для демо на 10 дней это потенциально подходит, но потребуются отдельные web/DB deployment и адаптация раздачи static/HTTPS под платформу; исходный Compose из трёх сервисов там не запускается целиком. Free-тариф не даёт обычную shell/one-off jobs для импорта. Аккаунт/проверка карты и деплой нами не проверялись, поэтому это запасной путь, а не гарантированная публикация без карты.
